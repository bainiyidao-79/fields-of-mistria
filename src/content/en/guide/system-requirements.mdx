Fields of Mistria is a very lightweight game. The official Steam requirements ask for a 64-bit Windows 10 machine with **6 GB of RAM, a GTX 460 (1 GB) or Radeon R7 240 (1 GB) class GPU, and 2 GB of storage** — hardware from over a decade ago. If your PC runs games from the last ten years at all, you are at or above the floor.

## Official Windows Requirements

| Component | Minimum | Recommended |
| --- | --- | --- |
| OS | Windows 10 (64-bit) | Windows 10 (64-bit) |
| Processor | Intel Core2 Duo E6400 or AMD Phenom X2 Dual-Core GP-7730 | AMD Ryzen 3 3300X |
| Memory | 6 GB RAM | 8 GB RAM |
| Graphics | NVIDIA GeForce GTX 460 1GB or AMD Radeon R7 240 1GB | AMD RX 480 8GB |
| DirectX | Version 11 | Version 11 |
| Storage | 2 GB available space | 2 GB available space |

## Linux Requirements

The [native Linux build](/release/platforms) lists matching hardware. Note the store page contains a units typo in the Linux block — it prints "6 MB RAM / 2 MB storage" where gigabytes are clearly intended:

| Component | Minimum | Recommended |
| --- | --- | --- |
| OS | Ubuntu LTS (Unity, GNOME, or KDE) | Ubuntu LTS (Unity, GNOME, or KDE) |
| Processor / Graphics | Same as Windows minimum | Same as Windows recommended |
| Memory / Storage | 6 GB RAM / 2 GB space | 8 GB RAM / 2 GB space |

## What the Numbers Mean in Practice

- **The minimum GPU is a 2010 card.** Modern integrated graphics (Intel Iris Xe, AMD Radeon 600M series and newer) clear the GTX 460 bar comfortably, though NPC Studio does not officially rate iGPU tiers.
- **Storage is trivial.** The requirement says 2 GB free; the actual download is roughly 305 MB and occupies around 615 MB on disk — smaller than most photo libraries.
- **Steam Deck runs it natively.** Fields of Mistria is [Steam Deck Verified](/release/platforms), meaning Valve tested the default configuration end to end on the handheld's hardware — itself proof of how low the demands are.
- **Crashes on old machines?** If your hardware genuinely sits under these minimums, that is the first suspect — see our [crash troubleshooting guide](/guide/crash-fixes).

## Quick Answers

- **Does it need a gaming PC?** No — the stated floor is entry-level 2010 hardware, and the recommended tier is a budget quad-core.
- **Windows 11?** Requirements list Windows 10; Windows 11 runs Windows 10 software, though it is not explicitly named on the store page.
- **How much space do I need?** 2 GB per the official listing; expect under 1 GB in practice.
