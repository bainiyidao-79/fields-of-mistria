Fields of Mistria is available **exclusively on Steam for PC**. There is one storefront, one purchase, and two operating systems: the game ships with native **Windows** and **Linux** builds, and it holds **Steam Deck Verified** status, meaning Valve's own testing found it plays well out of the box on the handheld.

## Platform Support at a Glance

| Platform | Status | Notes |
| --- | --- | --- |
| Windows (Steam) | ✅ Supported | The primary build; 64-bit |
| Linux (Steam) | ✅ Supported | Native depot, not a Proton translation |
| Steam Deck | ✅ Verified | Default graphics config certified by Valve |
| macOS | ❌ Not supported | No Mac requirements listed on the store page |
| Nintendo Switch / PlayStation / Xbox | ❌ Not released | NPC Studio's FAQ says the team is "currently evaluating additional platform support" |

## What "Steam Exclusive" Means in Practice

Every copy of Fields of Mistria — from the June 2024 demo through the [August 5, 2026 1.0 release](/release/release-date) — lives on Steam. Buying once covers everything: the full game, every content update, and [Steam Cloud saves](/release/price) for one [$13.99](/release/price) purchase. There is no Epic Games Store, GOG, or subscription service version, and no physical edition.

## A Rare Native Linux Release

Native Linux support deserves the callout: the Linux depot is a real 64-bit build rather than a Proton wrapper, which is uncommon for indie farm sims. One quirk worth knowing — the store page's Linux requirements block contains a units typo ("6 MB RAM"), where gigabytes are clearly intended; the [real requirements are modest](/guide/system-requirements) either way.

## Controller Players Are Covered Too

Whichever PC platform you pick, [full controller support](/guide/controller-support) is built in — Steam flags native Xbox, DualShock, and DualSense pad compatibility, so couch play on a Steam Deck or living-room PC works without remapping.
